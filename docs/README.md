# hdr-gainmap 技术文档

这套文档配合 [hdr-gainmap](../README.md) 阅读，回答的不是"怎么敲命令"，而是**为什么这样算**：HDR 的标准体系怎么来的、PQ 在编码什么亮度、增益图为什么用 log2 存比值、五种容器各自把色彩信息写在哪几个字节里、以及一个 2D 图像程序能借用多少 3D 渲染的光照知识。

三处结构性选择也写在文档里：增益图是**全分辨率 RGB 三通道**（逐通道增益，JPEG 用 ISO 21496-1 的 141 字节三段布局）、算法先做一次**光场分析**（光源 → 光束步进 → 辐照度 → AO → 深度代理）再估发光度、所有 HDR 输出**统一 PQ + BT.2020**（HLG 只作为标准对照保留在 01/02）。

命令、参数、安装、性能数字以 [README.md](../README.md) 为准；这里只讲原理、取舍和验证过程。

## 格式速查

| 格式               | 文档                         | 位深                     | 色度    | HDR 承载方式                           | SDR 回退           | 体积（1600×669 实测） |
| ---------------- | -------------------------- | ---------------------- | ----- | ---------------------------------- | ---------------- | --------------- |
| JPEG + Ultra HDR | [05](05-jpeg-ultra-hdr.md) | 8bit 基图 + 8bit RGB 增益图 | 4:4:4 | 增益图 + MPF + XMP + ISO（三通道 141B）    | 基图直接可看           | 0.87MB          |
| PNG              | [06](06-png.md)            | 16bit                  | 4:4:4 | cICP(9/16/0/1) + mDCV/cLLI + PQ 码值 | 查看器自行解释（多按 sRGB） | 3.94MB          |
| HEIC 10/12       | [07](07-heic.md)           | 10/12bit               | 4:2:0 | HEVC Main10/12 + nclx(9/16/9)      | 查看器 tone mapping | 0.36MB          |
| AVIF             | [08](08-avif.md)           | 12bit                  | 4:4:4 | AV1 + nclx(9/16/9)                 | 查看器 tone mapping | 1.73MB          |
| JPEG XL          | [09](09-jpeg-xl.md)        | 24bit                  | 4:4:4 | 码流内 cICP（Rec2100PQ）                | 查看器自行解释          | 5.73MB          |

一句话取舍：**要兼容选 JPEG，要无损存档选 PNG，要苹果生态选 HEIC，要网页选 AVIF，要极限位深/验证选 JXL。**

## 范围声明

* 本项目是 **2D 图像处理**，不是 3D 渲染器：没有深度、法线、材质、光源方向，因此第 10 章的光追/GI/AO 只作为"思想来源"和"命名依据"。`light.py` 里的"光线步进"是亮度场上的扩散积分，不是几何光线，没有求交、没有阴影射线。
* 不涉及视频编码、HDR 视频母版、色彩管理引擎的完整实现；ICC 只做输入归一化。
* 不是摄影教程：不教打光、构图、调色，只解释这些操作在物理/感知上对应什么量。
* 数值以代码为准。文档里的公式若与代码不一致，以代码为准并欢迎提 issue。
