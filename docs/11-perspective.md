# 11 图画的基本知识：空间透视

前六篇讲的是"光"和"文件"。这一篇换到画画这边：一张平面图为什么能让人看出"远"和"近"。

中文里的"透视"常把两件事混在一起：

* **线性透视**（linear perspective）：平行线在画面上汇聚到消失点，物体按距离缩小。
* **空气透视 / 空间透视**（aerial / atmospheric perspective）：远处的东西对比度低、颜色淡、偏蓝、细节少。

两者都是"深度线索"，但机制不同：一个靠几何，一个靠大气和视觉。画一张有空间感的图，通常两个都要用。

## 1. 透视的本质：把三维投影到二维

人眼和相机都是把三维场景投影到一个平面上。用针孔模型描述[\[7\]](#r7)：

```text
x = f · X / Z
y = f · Y / Z
```

* `(X, Y, Z)`：场景点，`Z` 是沿视线方向的距离；
* `f`：焦距（像素或毫米）；
* `(x, y)`：成像平面上的坐标。

两个直接结论：

1. **像的大小 ∝ 1/Z**：距离翻倍，成像高度减半。
2. **平行于视线的线汇聚到一点**：`Z → ∞` 时 `(x, y) → (0, 0)`，即画面中心（主点）。

这就是透视的数学全部。剩下的规则——地平线、消失点、视高——都是它的推论。

### 1.1 视场角

传感器宽度 `d`、焦距 `f` 时，水平视场角[\[5\]](#r5)：

```text
FOV = 2 · arctan(d / (2f))
```

全画幅（36mm 宽）的常见值：

| 焦距     | 水平 FOV | 观感      |
| ------ | ------ | ------- |
| 14 mm  | 104°   | 超广角，强透视 |
| 24 mm  | 74°    | 广角      |
| 35 mm  | 54°    | 小广角/人文  |
| 50 mm  | 40°    | "标准"    |
| 85 mm  | 24°    | 中长焦，人像  |
| 200 mm | 10°    | 长焦，压缩   |

"50mm 是标准"是因为它的对角线视场接近人眼的"清晰视野"，不是物理定律。

## 2. 线性透视：消失点与地平线

### 2.1 三个关键元素

* **视点（eye point）**：观察者眼睛的位置。
* **画面（picture plane）**：成像的平面。
* **地平线（horizon line）**：过视点、平行于地面的平面与画面的交线。**地平线的高度 = 眼睛的高度。**

所有**水平方向**的平行线，其消失点都落在同一地平线上[\[2\]](#r2)。这是判断一张透视图"对不对"的最快方法：找几条本应平行的线，延长，看它们是否交在地平线的同一点。

### 2.2 一点透视

正对场景（视线垂直于一个主立面），只有一个消失点（深度方向），水平/垂直方向保持平行。

典型：走廊、正面建筑、铁路轨道。适合"正面、稳定、仪式感"的构图。

### 2.3 两点透视

视线与两个立面都成角度，有两个消失点（分别对应两组水平平行线），垂直线仍保持垂直。

典型：街角建筑、室内斜看。最接近日常观看经验，也最常用。

### 2.4 三点透视

两点透视 + 俯视/仰视：垂直线也汇聚到第三个消失点（天点或地点）。

典型：高楼仰视、鸟瞰。注意：**只有画面倾斜（或镜头俯仰）时才会有第三消失点**；如果保持垂直，垂直线永远平行。

### 2.5 多点与曲线透视

* **四点/五点透视**：用于鱼眼、全景，直线变成曲线。
* **曲线透视**：严格说，真实透视的直线在平面上仍是直线；曲线来自镜头畸变或球面投影，不是"更高级的透视"。

### 2.6 一个数值例子

设焦距 `f = 1000 px`，一条水平线相对画面偏转 30°，其消失点横坐标：

```text
x = f · tan(30°) ≈ 577 px
```

偏 45° → `x = 1000 px`；偏 60° → `x ≈ 1732 px`。角度越大，消失点离画面中心越远；到 90° 时趋于无穷（线平行于画面，不汇聚）。

这也解释了广角为什么"透视强"：同样的场景，广角把更大的角度范围压进画面，边缘的消失点被拉得很远，近处物体相对显得更大。

## 3. 缩放与间距：1/Z 的后果

### 3.1 等距物体的像高

一排等距 `ΔZ` 的同样物体，像高 `h ∝ 1/Z`：

| 距离   | 相对像高  |
| ---- | ----- |
| 2 m  | 1.00  |
| 4 m  | 0.50  |
| 8 m  | 0.25  |
| 16 m | 0.125 |

每远离一倍距离，像高减半。这就是"近大远小"。

### 3.2 画面上的间距递减

等距物体在画面上的间距也按 `1/Z` 递减：近处稀疏、远处密集，最终挤向消失点。画一排柱子/树/窗时，如果间距等分，看起来就会"飘"。

### 3.3 为什么长焦"压缩"

常听到"长焦把背景拉近了"。严格说，**压缩感来自拍摄距离，不是焦距本身**。要拍同样大小的主体，长焦必须站得更远；站得远，主体与背景的相对距离差变小，`1/Z` 的变化就小，背景显得更大、更"贴"[\[4\]](#r4)。

举例：主体在 2m、背景在 10m，距离比 5:1；退到 20m 拍（主体 20m、背景 28m），距离比 1.4:1。后者的前景/背景大小差异明显更小。广角的"夸张"则是反过来：站得近，近处物体占满画面，远处迅速缩小。

所以：

* **透视由相机位置决定**，焦距只决定"截取多大范围"。
* 同一位置换焦距，透视关系不变，只是裁剪不同（"透视畸变"是另一回事，见 3.4）。

### 3.4 广角畸变 vs 透视

* **透视畸变**（perspective distortion）：广角近拍时，边缘物体被"拉伸"；这是投影的几何结果，不是镜头缺陷。
* **桶形/枕形畸变**（barrel/pincushion）：镜头光学缺陷，直线变弯。
* **全景/鱼眼**：投影方式不同，直线也会弯。

三者经常被统称"广角畸变"，但成因不同：一个改位置就好，一个要换镜头，一个要换投影。

## 4. 空气透视（空间透视）

### 4.1 现象

距离越远，物体看起来[\[3\]](#r3)：

1. **对比度下降**：亮的不那么亮，暗的不那么暗；
2. **颜色变淡/偏蓝**（白天）：饱和度下降，色相向大气光偏移；
3. **细节减少**：高频被大气散射和衍射模糊；
4. **整体变亮**：大气光叠加进来，黑位被"抬起来"；
5. **色温偏冷**（晴天）或偏暖（日落/雾霾）。

### 4.2 物理机制

* **瑞利散射**：气体分子对短波散射强（`∝ 1/λ⁴`），所以天空是蓝的，远处景物叠加了一层"蓝光"[\[1\]](#r1)。
* **米氏散射**：雾、尘、水滴对波长不敏感，远处发白、发灰。
* **吸收**：水汽、污染物按 Beer–Lambert 衰减。
* **对比度衰减**：散射把直射光"洗"成环境光，路径越长，对比度越低。

一个常用的近似：

```text
C(d) = C₀ · e^(−βd) + C_air · (1 − e^(−βd))
```

`C₀` 是物体固有对比度，`C_air` 是大气光，`β` 是消光系数。`d → ∞` 时 `C → C_air`，也就是"远处都变成雾的颜色"。

### 4.3 绘画中的应用

* **远山**：不是"把山画小"，而是"把山画淡、画蓝、画低对比"。
* **层次**：近景高对比、中景中对比、远景低对比，三层就够拉开空间。
* **空气光**：远景整体加一层偏蓝/偏灰的"雾"，但不要盖住轮廓。
* **暖冷对比**：近处暖、远处冷（或反过来，看光源），比单纯"变淡"更有空气感。
* **细节**：远处不要画窗框、砖缝；画了反而"贴脸"。

达·芬奇在《蒙娜丽莎》背景里用的就是这套：远山蓝灰、轮廓柔、细节少。中国山水画的"远山如黛"也是同一原理，只是用墨色浓淡代替了蓝灰。

### 4.4 空气透视 vs 线性透视

|      | 线性透视      | 空气透视           |
| ---- | --------- | -------------- |
| 依据   | 几何投影      | 大气散射/吸收        |
| 表现   | 缩小、汇聚、遮挡  | 变淡、偏蓝、低对比、少细节  |
| 失效条件 | 长焦远拍、正面平面 | 真空/太空、极干燥空气、夜景 |
| 绘画手段 | 消失点、辅助线   | 色彩、明度、虚实       |

两者独立：一张图可以线性透视很准但毫无空气感（像 CAD 渲染），也可以空气感很强但透视很平（像装饰画）。

## 5. 其他深度线索

除了两大透视，人眼还靠这些判断远近[\[6\]](#r6)：

| 线索    | 机制          | 绘画/摄影中的表现     |
| ----- | ----------- | ------------- |
| 遮挡    | 前面的挡住后面的    | 最强的深度线索，优先于大小 |
| 相对大小  | 熟悉物体的大小     | 人、车、窗、砖       |
| 纹理梯度  | 表面纹理随距离变密   | 草地、地砖、水面      |
| 阴影    | 阴影方向/软硬     | 接触阴影、投影长度     |
| 焦点/景深 | 离焦模糊        | 前景/背景虚化       |
| 运动视差  | 近处移动快       | 视频/游戏，静图没有    |
| 色彩/明度 | 近暖远冷、近实远虚   | 空气透视          |
| 位置    | 越靠上越远（地面场景） | 画面下方的物体通常更近   |

绘画时不需要全用；通常"遮挡 + 线性透视 + 空气透视"三件套就足够。

## 6. 常见错误

1. **消失点不共线**：同一组平行线的消失点必须在地平线上；画歪了整张图会"塌"。
2. **地平线高度混乱**：地平线 = 视高；俯视、仰视、平视只能选一个。
3. **把"长焦压缩"归因于镜头**：本质是拍摄距离；同一位置换焦距不改变透视。
4. **等距物体等间距**：画面上的间距应按 `1/Z` 递减。
5. **远景画得太清楚**：细节和对比度都要降，否则"贴脸"。
6. **空气透视只加蓝**：还要降对比、降饱和、抬黑位，只加蓝会像蒙了一层滤镜。
7. **广角畸变和镜头畸变混为一谈**：一个改机位，一个换镜头。

## 7. 和 HDR / 增益图的关系

这一节是"为什么一本 HDR 文档要讲透视"的答案。

### 7.1 远景的亮度结构

空气透视会**抬高远景的黑位**：大气光叠加进来，原本该暗的山谷变亮、变灰。这在亮度直方图上表现为"远处整体向中间灰靠拢"。

对本项目的启发式来说，这意味着：

* 远景（尤其天空、雾、远山）本来就是"大面积、偏亮、低对比"的区域，容易被 `lit`（局部亮）和 `white`（高亮）判据命中。
* 项目的 `area` 惩罚（大面积亮区降权）会压制天空/远山，避免它们被整体抬亮——这是对的，因为"亮"不等于"发光"。
* 但小面积的远景高光（远处的灯、水面反光）仍会被 `spark` 抬亮，这通常也符合直觉：远处的灯确实该亮。

### 7.2 大气光不是自发光

初学者容易把"远处的亮"当成"发光"。物理上，远景的亮度来自**散射的大气光**，不是物体自己发光。两者的 HDR 处理不同：

* 自发光（灯、太阳）可以到几千 nits，增益应该大；
* 大气光（雾、天空）是环境光，亮度有限，增益应该小。

本项目无法区分两者，只能靠"面积 + 局部对比"猜。这是 2D 输入的上限（见 [10](10-light-and-rendering.md) 第 8 节）。

### 7.3 高光随距离变"糊"

真实场景里，远处的点光源经过大气散射和镜头衍射，会在画面上形成一个小光斑，而不是一个像素。这就是"远处的灯看起来更糊、更大、更淡"。

本项目的 `halo`（大半径高光混合）和 `finalize` 的高斯模糊，在观感上模拟了这种"高光扩散"；但它作用于全图，不区分距离。如果一张图里同时有近处锐利高光和远处雾状高光，算法只能给一个折中。

### 7.4 空气透视在代码里的落点

`hdrgainmap/light.py` 把这一节的现象写成了两条公式：

```text
depth = 0.55 · 画面垂直位置 + 0.45 · (1 − 局部对比度)
atten = exp(−1.1 · depth)
field = field · atten + 0.06 · (1 − atten) · p90
```

* `depth` 是**深度代理**：越靠画面上方、局部对比越低，就越"远"。它不是真实的 Z，只用了绘画里两条最稳的线索——地平线在上、远处细节少。
* `atten` 让远处的辐照度衰减（介质吸收 + 散射把光"分走"）；
* 加上去的 `0.06·(1−atten)·p90` 是**大气光**：远处叠一层约为画面 90 分位亮度 6% 的底光，等效于"黑位抬高、对比度下降"。

结果是：远景的 `irradiance` 小、增益小，近景光源的传播不受影响。这正是 7.2 想要的"大气光不该被当成自发光"。参数 `1.1`（吸收系数）和 `0.06`（大气光比例）在 `light.py` 里是常量 `AERIAL_BETA`、`AERIAL_SKY`，可以按画风调。

### 7.5 构图建议（给写文档/做测试图的人）

* 测试增益图时，选**有明确光源 + 有远景层次**的图：近景暗、中景受光、远景雾化。
* 如果整张图都是平光、无高光，增益图几乎不起作用（`untouched` 比例接近 100%），这是正常的。
* 如果整张图都是大面积天空，`area` 惩罚会压制增益，输出接近原图——这也是设计意图，不是 bug。

## 8. 一页速查

```text
线性透视：
  地平线 = 视高
  平行线 → 消失点（在地平线上）
  像高 ∝ 1/Z
  FOV = 2·arctan(d/2f)
  压缩感来自距离，不来自焦距

空气透视：
  远 → 对比低、饱和低、偏蓝、细节少、黑位抬高
  近似：C(d) = C₀·e^(−βd) + C_air·(1 − e^(−βd))

深度线索优先级：
  遮挡 > 相对大小 > 线性透视 > 空气透视 > 纹理/阴影/虚实
```
