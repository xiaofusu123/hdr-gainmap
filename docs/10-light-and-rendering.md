# 10 光：原理、传播、反射、光追、全局光照与环境光遮蔽

这一篇是"补课"：增益图算法里出现的每一个词——照度、反射率、环境光、高光、遮蔽——都来自光的物理和渲染。把这条链走一遍，才能判断哪些能在 2D 图上近似、哪些根本做不到。

先给结论：**本项目不是渲染器。** 它没有深度、法线、材质、光源方向，只有一张亮度场。下面讲的光传输理论，是"我们近似了什么"的参照系，不是"我们实现了什么"的清单。

## 1. 光的原理

### 1.1 波与粒子

光同时表现为电磁波和光子：

* 作为波：振荡的电场和磁场，真空中速度 `c = 299792458 m/s`，频率 `ν` 与波长 `λ` 满足 `c = λν`。
* 作为粒子：一份一份的能量，单个光子能量 `E = hν = hc/λ`，`h = 6.62607015×10⁻³⁴ J·s`。

日常渲染用波动/几何光学就够了；只有涉及光电效应、传感器噪声、量子效率时才需要光子图像。

可见光大致 380–780 nm（常写 380–750 nm），频率约 400–790 THz。按波长粗分：

| 波段 | 波长范围       | 视觉          |
| -- | ---------- | ----------- |
| 紫外 | < 380 nm   | 不可见（部分动物可见） |
| 紫  | 380–450 nm | 偏蓝紫         |
| 蓝  | 450–495 nm | 蓝           |
| 绿  | 495–570 nm | 绿（人眼最敏感）    |
| 黄  | 570–590 nm | 黄           |
| 橙  | 590–620 nm | 橙           |
| 红  | 620–750 nm | 红           |
| 红外 | > 750 nm   | 不可见（热）      |

"380–780"和"380–750"的差异来自边界定义和个体差异，不影响工程结论。

### 1.2 颜色是"三刺激值"，不是光谱

人眼有三种视锥，峰值约 420 nm（S）、534 nm（M）、564 nm（L）。进入眼睛的光谱功率分布（SPD）被积分成三个响应值，大脑再解释成颜色。

**无穷多种 SPD 可以给出同一组三刺激值**，这叫同色异谱[\[1\]](#r1)。这是 RGB 显示能成立的前提，也是"屏幕上的橙色"和"夕阳的橙色"光谱并不相同的原因。色域、白点、ICC 这些概念都建立在这个近似上（见 [03](03-color-gamut-and-depth.md)）。

### 1.3 辐射度量与光度量

同一件事有两套单位：物理的（辐射度量）和视觉加权的（光度量）。

| 量    | 符号 | 单位          | 含义            |
| ---- | -- | ----------- | ------------- |
| 辐射通量 | Φe | W           | 单位时间能量        |
| 辐射强度 | Ie | W/sr        | 单位立体角通量       |
| 辐照度  | Ee | W/m²        | 落在表面上的功率密度    |
| 辐射亮度 | Le | W/(m²·sr)   | 单位面积、单位立体角的功率 |
| 光通量  | Φv | lm          | 视觉加权后的通量      |
| 发光强度 | Iv | cd = lm/sr  | 视觉加权后的强度      |
| 照度   | Ev | lx = lm/m²  | 视觉加权后的辐照度     |
| 亮度   | Lv | cd/m² = nit | 视觉加权后的辐射亮度    |

换算靠视见函数 `V(λ)`：人眼在 555 nm（绿光）最敏感，此波长 `1 W = 683 lm`；其他波长按 `V(λ)` 打折。所以"1 瓦的绿光"比"1 瓦的蓝光"看起来亮得多。

渲染里说的"亮度"通常指 `Lv`（nit），而辐射传输方程里的 `L` 是 `Le`（W/(m²·sr)）。两者差一个 `V(λ)` 加权，但在固定白点、固定色域的工程语境里经常混用——只要别在跨色域换算时混。

### 1.4 人眼：对数感知与适应

人眼能工作的亮度范围约 `10⁻⁶–10⁸ cd/m²`，但**瞬时**动态范围只有约 12–14 stops[\[2\]](#r2)；SDR 显示约 5–8 stops。人眼靠瞳孔、光化学适应、神经适应在不同亮度间切换。

感知大致服从 Weber–Fechner 定律[\[13\]](#r13)：`ΔL/L ≈ 常数`（约 1–2%）。这就是为什么：

* PQ 按感知分配码值（[02](02-pq-and-brightness.md)）；
* 增益图用 log2 存比值（[04](04-gain-map.md)）；
* 暗部比亮部更容易看出 banding。

也是为什么"HDR 更亮"是个误解：人眼适应了新亮度后，绝对亮度会被重新归一化；HDR 的价值在**同时**看到的范围，不在峰值数字。

## 2. 传播

### 2.1 直线传播与几何光学

当波长远小于物体尺寸时，光近似沿直线走，这就是几何光学。反射、折射、成像、阴影都建立在这个近似上。

几何光学的三个基本定律：

1. 光在均匀介质中沿直线传播。
2. 独立传播：两束光相交，各自继续，互不影响（非相干光）。
3. 反射与折射定律（见第 3 节）。

### 2.2 平方反比

点光源在距离 `r` 处的照度：

```text
E = I / r²
```

因为同样的功率摊在半径 `r` 的球面上，面积是 `4πr²`。距离翻倍，照度降到 1/4。

对**面光源**和**环境光**，平方反比不直接适用（近场尤其明显）；渲染里要么按面积积分，要么用近似模型。这也是为什么"环境光"不能简单当成一个远处点光源。

### 2.3 朗伯表面与 π

朗伯（漫反射）表面的辐射亮度 `L` 与方向无关。它的出射辐照度（辐出度）是：

```text
M = ∫_Ω L cosθ dω = L ∫_Ω cosθ dω = πL
```

半球积分的 `∫cosθ dω = π`，所以 `M = πL`。反过来，若表面反射率是 `ρ`，入射照度 `E`，则 `L = ρE/π`，对应 BRDF `f_r = ρ/π`（见 3.2）。

这个 `π` 是很多"亮度算不对"的来源：把 `ρE` 直接当 `L`，会亮 π 倍。

### 2.4 惠更斯–菲涅耳原理

波前上的每一点都可以看作次级球面波的源，后续波前是这些子波的包络[\[3\]](#r3)。它解释了衍射和干涉，也是"光会绕过障碍物"的数学基础。几何光学是它在 `λ → 0` 时的极限。

### 2.5 散射

光在介质中遇到微小颗粒会偏离原方向：

| 类型   | 尺度             | 波长依赖     | 现象           |
| ---- | -------------- | -------- | ------------ |
| 瑞利散射 | 颗粒 ≪ λ（气体分子）   | `∝ 1/λ⁴` | 天空蓝、夕阳红、远处偏蓝 |
| 米氏散射 | 颗粒 ≈ λ（雾、云、尘埃） | 弱        | 雾天发白、光晕      |
| 几何散射 | 颗粒 ≫ λ（雨滴）     | 无        | 彩虹、雨幕        |

瑞利散射[\[10\]](#r10) 的 `1/λ⁴` 意味着蓝光被散射得比红光强约 `(700/450)⁴ ≈ 5.9` 倍。所以：

* 天空是蓝的（散射光进入眼睛）；
* 夕阳是红的（蓝光被散射走，直射光剩红）；
* 远处的山偏蓝、偏淡（大气散射叠加）。

这在绘画里叫**空气透视/空间透视**，见 [11](11-perspective.md)。

### 2.6 吸收与 Beer–Lambert

光穿过吸收介质，强度按指数衰减[\[12\]](#r12)：

```text
I = I₀ · e^(−αL)
```

`α` 是吸收系数，`L` 是路径长度。水、雾、彩色玻璃都适用。渲染里用它做"体积雾""水下颜色"。

### 2.7 衍射

光绕过障碍物/通过孔径时，会偏离直线。两个经典结果：

* **单缝**：暗纹满足 `a·sinθ = mλ`（`a` 缝宽，`m = ±1, ±2, …`）。
* **圆孔**：艾里斑，第一暗环 `sinθ = 1.22 λ/D`（`D` 孔径）[\[11\]](#r11)。

由此得到**瑞利判据**：两个点光源刚好能分辨的最小角距离

```text
θ_min = 1.22 λ / D
```

对摄影的意义：光圈越小（`D` 越小），衍射斑越大，分辨率越低。所以"光圈开到 f/22 更锐"是错的——到一定程度衍射会吃掉锐度。对渲染的意义：衍射是一个**低通滤波器**，真实镜头的高光会带一点"软边"，而不是数学上的零宽点。

本项目没有做衍射，只有 `spark`（点状高光）和 `halo`（大半径混合）来近似"高光溢出"的观感。

## 3. 反射与折射

### 3.1 镜面反射与漫反射

* **镜面反射**：入射角等于反射角，`θi = θr`，方向集中。
* **漫反射**：光向半球各方向散开，方向分布接近朗伯（`L` 与方向无关）。

真实表面介于两者之间：粗糙度决定高光的宽度，菲涅耳决定高光的强度随角度变化。

### 3.2 BRDF

双向反射分布函数（BRDF）[\[7\]](#r7) 定义为"出射辐射亮度 / 入射辐照度"：

```text
f_r(ωi, ωo) = dL_o(ωo) / dE_i(ωi)
```

单位 `sr⁻¹`。两个性质：

* **互易性**：`f_r(ωi, ωo) = f_r(ωo, ωi)`（光路可逆）。
* **能量守恒**：`∫_Ω f_r(ωi, ωo) cosθo dωo ≤ 1`（不能反射出比入射更多的能量）。

常见模型：

| 模型                     | 形式                     | 特点            |
| ---------------------- | ---------------------- | ------------- |
| 朗伯                     | `f_r = ρ/π`            | 最简，漫反射        |
| Phong                  | `ρ/π + k_s cos^n(α)/…` | 经验高光，`n` 控制锐度 |
| Blinn-Phong            | 用半角向量 `h` 代替反射向量       | 更快，高光更自然      |
| GGX / Trowbridge–Reitz | 微表面分布 + 几何项 + 菲涅耳      | 物理渲染常用        |

微表面模型把表面看成无数微小镜面，粗糙度对应法线分布宽度。宏观的"高光"是这些微镜面反射的统计结果。

### 3.3 菲涅耳

光从一种介质到另一种介质，反射率随入射角变化。非偏振光的菲涅耳反射率[\[8\]](#r8)：

```text
Rs = |(n1 cosθi − n2 cosθt) / (n1 cosθi + n2 cosθt)|²
Rp = |(n1 cosθt − n2 cosθi) / (n1 cosθt + n2 cosθi)|²
R  = (Rs + Rp) / 2
```

其中 `θt` 由 Snell 定律给出。垂直入射时：

```text
R0 = ((n1 − n2) / (n1 + n2))²
```

空气→玻璃（`n=1.5`）约 4%；空气→水（`n=1.333`）约 2%。掠射角（`θi → 90°`）反射率趋近 1——这就是为什么水面/桌面在低角度像镜子。

Schlick 近似：

```text
F(θ) = F0 + (1 − F0)(1 − cosθ)⁵
```

它在工程上足够准，且计算便宜，是实时渲染的默认选择。

### 3.4 折射与全反射

Snell 定律：

```text
n1 sinθ1 = n2 sinθ2
```

从光密介质到光疏介质（`n1 > n2`）时，入射角超过临界角会发生全反射：

```text
sinθc = n2 / n1
```

水→空气约 48.6°，玻璃→空气约 41.8°。光纤、水面倒影、钻石的"火彩"都和它有关。

### 3.5 色散

折射率随波长变化（`n(λ)`），不同颜色偏折角不同。棱镜分光、彩虹、镜头色差都是色散。渲染里通常忽略（或只在后期加一点色边），因为它对大多数场景是二阶效应。

### 3.6 偏振

光是横波，电场方向可以取向。反射、散射会改变偏振状态：

* 布儒斯特角 `θB = arctan(n2/n1)` 处，反射光完全偏振（空气→玻璃约 56.3°）。
* 天空的散射光是部分偏振的，偏振镜可以压暗天空。

渲染里偏振通常忽略；摄影里它是滤镜的基础。

## 4. 光线追踪

### 4.1 从光线投射到 Whitted

* **Ray casting**（1980 年代）：从相机向每个像素发射一条光线，求最近交点，着色。只处理可见性，不处理反射/折射。
* **Whitted 光线追踪**（1980）[\[4\]](#r4)：在交点处递归发射反射线、折射线、阴影线，处理镜面和透明。它是"递归光线追踪"的起点。
* **分布式光线追踪**：每个像素发射多条光线，采样面积光、景深、运动模糊，得到软阴影和模糊反射。

### 4.2 渲染方程

Kajiya 1986 年给出统一表述[\[5\]](#r5)：

```text
L_o(x, ωo) = L_e(x, ωo) + ∫_Ω f_r(x, ωi, ωo) · L_i(x, ωi) · (ωi · n) dωi
```

读法：

* `L_o`：从 `x` 沿 `ωo` 出去的辐射亮度；
* `L_e`：自发光；
* 积分项：来自半球所有方向的入射光 `L_i`，乘 BRDF、乘余弦因子。

它是递归的：`L_i` 本身又是另一个点的 `L_o`。直接光只算光源项，间接光要解这个递归——这就是全局光照。

朗伯表面简化为：

```text
L_o = L_e + (ρ/π) · E
```

其中 `E = ∫ L_i cosθ dωi` 是入射照度。

### 4.3 路径追踪

路径追踪用蒙特卡洛解渲染方程[\[6\]](#r6)：

```text
L_o ≈ (1/N) Σ f_r · L_i · cosθ / pdf
```

从相机出发，每步按 BRDF 采样一个新方向，直到命中光源或逃逸。要点：

* **重要性采样**：按 `pdf` 采样高贡献方向，方差更小。
* **俄罗斯轮盘赌**：按存活概率随机终止路径，避免无限递归且保持无偏。
* **噪声**：误差 `O(1/√N)`，所以"多一倍采样只降 1/√2 噪声"。
* **无偏**：期望值等于真实积分；光子映射则是有偏但一致。

路径追踪能自然处理：软阴影、景深、运动模糊、焦散、色溢、多次反弹。代价是噪声和算力。

### 4.4 光子映射与双向路径追踪

* **光子映射**：两遍法。第一遍从光源发射光子，记录在场景中；第二遍从相机出发，在交点附近做密度估计。适合焦散、参与介质；有偏。
* **双向路径追踪**：同时从相机和光源发射子路径，在中间连接。适合"小光源 + 大场景"的困难配置。

### 4.5 实时 GI 的近似

游戏/实时渲染用不起完整路径追踪，常见替代：

| 方法             | 思路                  |
| -------------- | ------------------- |
| 光照探针 / DDGI    | 在空间布点，预计算/更新辐照度     |
| 光照贴图（lightmap） | 烘焙到纹理               |
| SDF / 体素 GI    | 用距离场/体素做 cone trace |
| SSGI           | 屏幕空间射线，只处理可见部分      |
| Lumen（UE5）     | 距离场 + 屏幕追踪 + 探针混合   |
| ReSTIR         | 时空重采样，复用邻居样本        |

它们都在"用更少的样本换更低的噪声"，本质仍是渲染方程的近似解。

## 5. 全局光照

### 5.1 直接光、间接光、全局光

* **直接光**：光源 → 表面 → 相机，一次弹射。
* **间接光**：光源 → 表面 → 表面 → … → 相机，多次弹射。
* **全局光照（GI）**：直接 + 间接的统称[\[14\]](#r14)。
* **焦散**：光经镜面/折射后聚焦形成的亮斑（水面波纹投在墙上的光斑）。

间接光带来的视觉线索：

* **色溢**（color bleeding）：红墙旁边的白墙会偏红。
* **环境光**：天空/地面的大面积漫射，让阴影不是纯黑。
* **接触阴影/遮蔽**：物体交界处更暗，是"物体落地"的关键线索。

### 5.2 Radiosity

Radiosity 把场景离散成面片，解"每个面片接收多少能量"的线性方程组。它是**漫反射全局光照**的有限元解法，无噪声但开销大、不适合镜面。老一代建筑渲染常用。

### 5.3 为什么 GI 难

* 维度高：每个点要对半球积分。
* 递归：间接光又是别的点的直接光。
* 高频细节：阴影边缘、焦散需要大量样本。
* 实时约束：16ms 内要出画面。

所以实时渲染大量使用"预计算 + 近似 + 时域复用"，而离线渲染用路径追踪慢慢磨。

## 6. 环境光遮蔽（AO）

### 6.1 定义

环境光遮蔽[\[9\]](#r9) 衡量一个点被周围几何"挡住"了多少环境光：

```text
A(x) = (1/π) ∫_Ω V(x, ω) · (n · ω) dω
```

`V(x, ω)` 是可见性（0 或 1），`n·ω` 是余弦加权，`1/π` 归一化。结果是 `[0,1]`：1 = 完全开阔，0 = 完全被挡。

关键性质：

* **只与几何有关，与光源无关。** 它假设环境光是均匀的（常数 radiance），所以不需要知道光从哪来。
* **不是阴影。** 阴影是"某个光源被挡住"，AO 是"整个半球被挡住的比例"。
* **接触处最暗**：墙角、缝隙、物体与地面的交界。

### 6.2 常见算法

| 算法    | 数据      | 特点              |
| ----- | ------- | --------------- |
| SSAO  | 深度缓冲    | 屏幕空间采样，快，有噪声/光晕 |
| HBAO  | 深度 + 法线 | 水平角扫描，质量更好      |
| GTAO  | 深度 + 法线 | 解析积分，质量/性能平衡    |
| RTAO  | 光线追踪    | 物理准确，贵          |
| 烘焙 AO | 预计算     | 静态场景，质量最高       |

SSAO 的典型做法：在像素周围采样若干点，比较深度，统计被挡的比例，再模糊。它的"遮蔽"只在屏幕空间成立，屏幕外的几何不参与，所以边缘会有光晕。

### 6.3 2D 图像里的"伪 AO"

一张 2D 图没有深度，但**亮度场**里藏着类似的信号：物体交界处通常更暗（画师画的），缝隙、褶皱、头发根部也会压暗。所以可以用"局部暗度"近似 AO：

```text
near = guided(near_small)          # 小半径，用导向滤波保住物体边界
far  = 高斯 (Y, r_big)
ao   = clip((near + 0.02) / (far + 0.02), 0.45, 1.0)^0.9
env  = smoothstep(0.02, 0.45, far) · ao
amb  = 0.10 · env
```

直觉：`near/far` 小，说明这个点比周围大范围更暗——可能是缝隙/接触处，AO 就低，环境光贡献也低。`clip` 的下限 0.45 防止把暗部压死。小半径用导向滤波（以 `Y` 自身为导向）而不是纯高斯，边缘处的"暗缝"才不会被抹平。

这是**启发式**，不是物理 AO：它分不清"暗是因为遮蔽"还是"暗是因为材质本身黑"。白墙上的灰色图案会被误判，黑色物体旁边的亮面也可能被误判。第 8 节会讲这个局限。

## 7. 光追、GI、AO 和这张 2D 图的关系

### 7.1 光场分析的实现

`hdrgainmap/light.py` 用一次 `analyze()` 把亮度场拆成五样东西：光源、光束、辐照度、AO、深度代理。全部在 640 长边的降采样图上做，最后双线性放回原尺寸。

**光源**：亮度高于第 97 百分位的像素才算候选，再按亮度归一：

```text
src = clip((Y − p97) / (max − p97), 0, 1)^1.4
```

指数 1.4 让只有明显的高光才接近 1，普通亮部留在 0 附近。

**光束**：沿 8 个方向做"光线步进"。这不是几何光线，而是把亮度沿方向逐步扩散、衰减的积分，模拟光在介质里的传播：

```text
tau = 0.45 + 0.55·Y                 # 亮处传播得更远
F   = S + 0.88 · shift(F, dir) · tau # 40 步，8 方向取平均
```

`shift` 越界补 0，避免 `np.roll` 的环绕伪影。结果按 99.5 百分位归一。

**漫反射**：4 个尺度的高斯，`σ = base·2^k`，权重 `σ^-1.75`（幂律衰减，尾部近似 `1/r^p`），模拟光线在粗糙表面间的多次散射。

**合成辐照度**：

```text
field = 0.68 · diffuse + 0.32 · beams
atten = exp(−1.1 · depth)            # 远处被介质吸收
field = field · (0.25 + 0.75·Y) · atten
        + 0.06 · (1 − atten) · p90   # 空气透视：远处叠一层大气光
```

`depth` 是深度代理：`0.55 · 画面垂直位置 + 0.45 · (1 − 局部对比度)`——越靠上、越缺细节的像素越"远"。这是空间透视在算法里的落点：远处对比度低，叠一层大气光后更淡、更蓝（见 [11](11-perspective.md)）。

**光色**：把光源像素的线性 RGB 取均值、再按亮度归一，得到 `light_color`，供分通道增益使用。

### 7.2 概念映射

把上面的概念映射到本项目的启发式，能看清"近似了什么"：

| 物理/渲染概念  | 本项目对应                     | 近似程度           |
| -------- | ------------------------- | -------------- |
| 光源       | `lit`（局部亮于周围）             | 弱：只按亮度，不分辨光源类型 |
| 光照扩散     | 光线步进 + 4 尺度漫反射            | 中：模拟光晕/环境光扩散   |
| 直接光      | `base_lit · lit`          | 弱：没有光方向        |
| 环境光      | `base_amb · env`          | 中：用 AO 调制      |
| 环境光遮蔽    | `near/far` 比值             | 弱：亮度场代理，无几何    |
| 镜面高光     | `spark`（点状峰值）             | 弱：只按局部对比       |
| 眩光/bloom | `halo` 混合 + `finalize` 饱和 | 中：多半径混合        |
| 多次反弹/色溢  | 无                         | 无              |
| 焦散       | 无                         | 无              |
| 色调映射     | `finalize` 指数饱和           | 中：压缩动态范围       |

做不到的根本原因：

1. **没有深度**：不知道哪个像素在前、哪个在后，无法判断遮挡。
2. **没有法线**：不知道表面朝向，无法算 `n·ω`、菲涅耳、高光方向。
3. **没有材质**：不知道反射率、粗糙度、金属度，无法区分"暗"和"被遮"。
4. **没有光源**：不知道光的颜色、强度、位置，无法做直接光积分。
5. **没有多视图**：单张图无法做立体匹配/多视角一致性。

所以本项目的"光传输"是**从亮度场反推光照结构**，不是解渲染方程。它利用的是画师的绘画习惯（光源画亮、缝隙画暗、高光画白），而不是物理规律。这也解释了为什么它在插画上效果不错、在照片上容易翻车：插画的亮度分布本来就是"按视觉语义"组织的。

## 8. 局限与边界

* **白墙/天空误判**：大面积平亮会被 `lit` 判成"发光"，导致整片被抬亮。项目用 `area` 惩罚（大面积亮区降权）缓解，但不能根除。
* **暗图噪点**：暗部噪声的局部峰值可能被 `spark` 当成高光，抬出彩色噪点。
* **网点/纹理**：漫画网点、织物纹理会被当成高频高光。
* **单通道判据**：发光判据本身只看亮度，最后的 `w_c`/`tint` 只是对光色与表面色的补偿，不是对每个通道独立反解光谱。饱和色的"亮"和"发光"仍可能混淆。
* **无方向**：不知道光从哪来，所以"阴影方向"完全靠画师，算法不补。
* **无多次反弹**：暗部不会因为旁边有亮墙而染上颜色。

这些不是实现 bug，是 2D 输入的信息上限。要突破，需要深度估计、材质分割、多视图，或者干脆换成 3D 渲染。
